# What's new (people-facing)

Write this list for each release: short, exciting, one line each, written for people using
the app. It becomes the "Highlights" in the release notes and the app's "What's new" window.
Only included when this file changed since the last release.

- Faster on-device AI: it starts loading as soon as you open + or the camera, and stays ready for 10 minutes instead of 3
- A typed food asks the AI a much shorter question, stops the moment the answer is complete, and is remembered, so the second time is instant
- About 150 everyday and Icelandic foods (plokkfiskur, kleina, skyr, pylsa, flatkaka…) now fill in instantly without the AI
- Meal photos show each food as soon as it's spotted, use a smaller picture, and no longer start over when an answer goes wrong part way
- Keep typing and the old answer stops at once; tap Done on the keyboard to look a food up straight away
- Foods added together are looked up in one go
- Settings › On-device AI shows whether the AI runs on the fast graphics chip or the slower main processor

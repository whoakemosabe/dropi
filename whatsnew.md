# What's new (people-facing)

Write this list for each release: short, exciting, one line each, written for people using
the app. It becomes the "Highlights" in the release notes and the app's "What's new" window.
Only included when this file changed since the last release.

- New Trends tab: your average, time in range and estimated A1C for 7, 14, 30 or 90 days
- Every reading on one chart over the target band; tap a dot to see it
- Insights in plain words: lows, fasting and after-meal patterns, how steady you are
- Averages by time of day, and a daily table
- A new tab bar with the big + right in the middle

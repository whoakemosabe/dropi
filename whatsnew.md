# What's new (people-facing)

Write this list for each release: short, exciting, one line each, written for people using
the app. It becomes the "Highlights" in the release notes and the app's "What's new" window.
Only included when this file changed since the last release.

- The home screen widget is redone so it's easy to read: a big clear number, the range as a coloured bar and a word, and nothing squeezed
- It adapts to its size: a slim row, a square, or a wide card with labelled Reading and Meal buttons
- Solid background, so your wallpaper never shows through the numbers

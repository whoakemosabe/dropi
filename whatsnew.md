# What's new (people-facing)

Write this list for each release: short, exciting, one line each, written for people using
the app. It becomes the "Highlights" in the release notes and the app's "What's new" window.
Only included when this file changed since the last release.

- Charts show readings as dots, never joined by a line that guesses what happened between checks
- Highs and lows carry their number on the day chart; tap "Values" to see every number
- New on Trends: Standard day, your usual value at each check time (on waking, after breakfast…), replacing "By time of day"

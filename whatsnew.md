# What's new (people-facing)

Write this list for each release: short, exciting, one line each, written for people using
the app. It becomes the "Highlights" in the release notes and the app's "What's new" window.
Only included when this file changed since the last release.

- Faster: meal rises are worked out once in the background instead of over and over, so Trends, Today and the meal screen no longer stutter with a sensor connected
- A meal you close before saving waits for you on Today and Meals, with Open and Discard
- "Your meal is ready" now arrives when you've switched to another app, not only when the meal screen was closed
- Deleting or moving a meal moves or removes its after-eating reminder too
- US labels: numbers are read per serving, with the serving size, so carbs come out right
- Fixed: the camera could reopen and lose a photo if Android closed Dropi while it was open
- Fixed: Save waits while a food's numbers are still being looked up, so nothing is saved as 0 g by accident
- Small fixes: the chart's tapped reading updates after an edit, sheets stack and close in the right order, and screen readers hear which chips are on

# What's new (people-facing)

Write this list for each release: short, exciting, one line each, written for people using
the app. It becomes the "Highlights" in the release notes and the app's "What's new" window.
Only included when this file changed since the last release.

- Scan a packet's barcode: Dropi looks it up in Open Food Facts and fills in the carbs, sugars, fibre, protein and fat (only the barcode number is sent)
- Packets you've scanned before, or whose numbers you typed, fill in instantly next time, even offline
- A packet's own serving (like a 170 g skyr pot) is offered as the amount eaten
- If a label photo can't be read but shows the barcode, Dropi looks the barcode up instead
- More › Report a problem: say what went wrong and send it, with what Dropi knows about the problem (no readings, meals or notes)

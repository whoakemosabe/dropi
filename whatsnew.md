# What's new (people-facing)

Write this list for each release: short, exciting, one line each, written for people using
the app. It becomes the "Highlights" in the release notes and the app's "What's new" window.
Only included when this file changed since the last release.

- Dropi 1.1: a new, denser look built like an instrument and a logbook, with less card clutter
- Today: your number with a range scale beside it, the whole day on one line, and one list of readings, meals and checks in time order
- Meals read like receipts, stamped with how each one went
- Trends: four numbers at a glance and a small chart for every day (weeks on 30 and 90 days); tap one to zoom in
- More shows how things stand at a glance: last backup, reminders, live sensor, on-device AI
